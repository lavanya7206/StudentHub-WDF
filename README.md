# StudentHub

## Project Description

StudentHub is a simple student portal website developed using HTML. It helps students access important college information such as registration, login, events, profile, contact details, and feedback.
This project was created as a beginner web development project.

## Features

- Home Page
- About Page
- Register Page
- Login Page
- Contact Page
- Dashboard Page
- Events Page
- Profile Page
- FAQ Page
- Feedback Page
- Admin Page

## Technology Used

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Use the navigation bar to visit other pages.
