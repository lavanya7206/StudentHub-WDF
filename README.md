# StudentHub

## Project Description

StudentHub is a simple student portal website developed using HTML. It helps students access important college information such as registration, login, events, profile, contact details, and feedback.
This project was created as a beginner web development project.

## Features

- Home Page
- About Page
- Register Page
- Login Page
- Contact Page
- Dashboard Page
- Events Page
- Profile Page
- FAQ Page
- Feedback Page
- Admin Page

## Technology Used

- HTML5
